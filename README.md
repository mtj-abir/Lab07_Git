# Temperature Converter - Main Version

## Purpose
Converts a temperature from Celsius to Fahrenheit and Kelvin.
Made for practising Git and GitHub (CS-117 Lab 7).

## How to run
python temperature_converter.py

## Example
Input:  Temperature in Celsius: 25
Output: Fahrenheit: 77.0
        Kelvin: 298.15
